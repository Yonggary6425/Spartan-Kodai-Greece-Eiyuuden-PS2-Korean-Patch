스파르탄 ~고대 그리스 영웅전~ (PS2 일본판 SLPM-66444) 한글패치 v1.0
by Yonggary6425 (용가리) - 본 한글패치는 개인이 제작한 비공식·비상업적 팬 한글패치입니다.

[적용 방법]  (Windows 기본 PowerShell 사용 - 별도 설치 불필요)
  A) ISO에 적용 (권장)
     원본 ISO를 "패치하기.bat" 위에 끌어다 놓으면 같은 폴더에 "원본이름 (Korean).iso"가 생깁니다.
     (원본 ISO는 수정하지 않음) "완료! (25/25 파일)"이 나오면 성공입니다.
  B) 압축 푼 게임 폴더에 적용
     게임 폴더(SLPM_664.44와 DATA 폴더가 있는 곳)를 "패치하기.bat" 위에 끌어다 놓으면
     그 옆에 DATA_KOR 폴더가 생기고 한글 PAK 25개가 들어갑니다. DATA 폴더의 파일과 교체 후 ISO로 다시 묶으세요.
  C) Python (macOS/Linux)
     python3 patch.py "원본.iso"   또는   python3 patch.py "게임폴더"

  - 바뀐 섹터만 덮어쓰며 파일 크기·위치(LBA)는 원본과 같습니다.
  - 적용 전후 MD5를 검사하므로 원본이 다르면 해당 파일은 건너뜁니다.
  - 반드시 원본 ISO에 적용하세요. (이전 패치본에 덮어 적용하지 마세요)

[주의]
  - 세이브 스테이트로 불러오면 이전 글꼴·문장이 보일 수 있습니다. 메모리 카드 세이브로 불러오세요.

[한글화 범위]
  - 게임 안 일본어 문장 3,645항목 전부 (메뉴·시스템·대사·목표·미션 설명)
  - 대사·실시간 컷신 자막·목표·미션 설명 2,030항목은 일본어 음성 기준으로 번역
  - 적 이름표(라틴어) 1,581개 구성 요소, 영문 잔존 142항목(난이도·전투 평가·제작진 직함 등)
  - 타이틀 로고, 한글화 크레딧 화면, localization by yonggary 표기
  - 글꼴: 나눔바른고딕 Regular (SIL OFL 1.1), 실시간 컷신 자막 기울임 없음
  - 표기: 그리스 인물은 그리스어 원음(카스토르, 폴리데우케스, 아테나이, 헬라스),
          로마 인물은 라틴어 원음(티베리우스, 세야누스). 시스템 안내는 해요체.
  - 음성은 일본어 그대로입니다.
